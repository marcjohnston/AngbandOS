## Accepted Acronym Legend

The following acronyms and abbreviations are accepted when used in their documented technical or domain meaning. The `IdentifierForm` column specifies the preferred form in C# identifiers.

|--------------------------|--------------------------------------------------------|-------------------------|--------------------------|
| Acronym/Abbreviation     | Meaning/Description                                    | IdentifierForm          | Platform                 |
|--------------------------|--------------------------------------------------------|-------------------------|--------------------------|
| `API`                    | Application Programming Interface                      | `Api`                   | General Software         |
| `ASP.NET`                | Active Server Pages .NET                               | `AspNet`                | ASP.NET Core             |
| `CLI`                    | Command-Line Interface                                 | `Cli`                   | General Software         |
| `DB`                     | Database                                               | `Db`                    | General Software         |
| `DI`                     | Dependency Injection                                   | `Di`                    | General Software         |
| `GUID`                   | Globally Unique Identifier                             | `Guid`                  | General Software         |
| `HTML`                   | HyperText Markup Language                              | `Html`                  | General Software         |
| `HTTP`                   | Hypertext Transfer Protocol                            | `Http`                  | General Software         |
| `HTTPS`                  | Hypertext Transfer Protocol Secure                     | `Https`                 | General Software         |
| `ID`                     | Identifier                                             | `Id`                    | General Software         |
| `JSON`                   | JavaScript Object Notation                             | `Json`                  | General Software         |
| `JWT`                    | JSON Web Token                                         | `Jwt`                   | General Software         |
| `SQL`                    | Structured Query Language                              | `Sql`                   | General Software         |
| `UI`                     | User Interface                                         | `Ui`                    | General Software         |
| `URL`                    | Uniform Resource Locator                               | `Url`                   | General Software         |
| `XML`                    | Extensible Markup Language                             | `Xml`                   | General Software         |
| `AI`                     | Artificial Intelligence                                | `Ai`                    | Game-Domain              |
| `NPC`                    | Non-Player Character                                   | `Npc`                   | Game-Domain              |
|--------------------------|--------------------------------------------------------|-------------------------|--------------------------|

All other game-domain abbreviations, including `AC`, `HP`, `LOS`, `MP`, `RNG`, `SP`, and `XP`, are not approved by this legend. Prefer descriptive names such as `HitPoints`, `LineOfSight`, `RandomGenerator`, `SpellPoints`, and `ExperiencePoints`.
